LeXWeft Lite のはじめかた

資料を入れると、課題と解決手段のつながりを Claude などの LLM と一緒に作り、図で見て、根拠の段落つきで探せるようになるアプリです。データはこの PC の中に保存します。

Mac の方Windows の方使い方困ったとき
必要なもの
  • macOS 12 以降、または Windows 10 / 11
  • インターネット接続（セットアップのときだけ。必要なものを取ってきます）
  • LLM とつなぐ場合は Claude Desktop（無料プランでも使えます）

はじめる前に、同じフォルダの TERMS.txt（テスト版の利用条件）をお読みください。

Mac での入れ方（5 分ほど）

  1. フォルダを置き場所に移す。 展開したフォルダを「書類」などに移します。
    セットアップのあとでフォルダを動かすと、起動と Claude との接続をやり直すことになります。
  2. ターミナルを開く。 ⌘ + スペースで Spotlight を開き、「ターミナル」と入力して Enter。
  3. セットアップを始める。 ターミナルに bash と半角スペースを 1 つ打ち、フォルダの中の install.sh をターミナルの画面にドラッグして、Enter。 
    bash /Users/あなたの名前/Documents/LeXWeftLite/install.sh
    のように表示されれば正しい形です。
  4. 数分待つ。 必要なものを取ってきて入れます。最後に「Claude Desktop に LeXWeft Lite を登録しますか」と聞かれたら y と打って Enter。
  5. 起動する。 フォルダにできた「LeXWeft Lite.command」をダブルクリック。ブラウザが開いて画面が出ます。
    使っている間は、一緒に開いたターミナルの窓を閉じないでください。終わるときはその窓を閉じます。

Windows での入れ方（5 分ほど）

  1. フォルダを置き場所に移す。 ZIP を右クリック →「すべて展開」し、できたフォルダを「ドキュメント」などに移します。
  2. PowerShell を開く。 そのフォルダをエクスプローラーで開き、上のアドレス欄に powershell と入力して Enter。
  3. セットアップを始める。 次を貼り付けて Enter。 
    powershell -ExecutionPolicy Bypass -File .\install.ps1
  4. 数分待つ。 最後に「Claude Desktop に LeXWeft Lite を登録しますか」と聞かれたら y と打って Enter。
  5. 起動する。 フォルダにできた「LeXWeft Lite.bat」をダブルクリック。ブラウザが開いて画面が出ます。

使い方

1. 資料を入れる

「資料」タブに、ファイル（md / txt / html / pdf / docx / csv）をドラッグします。フォルダのパスや URL も入れられます。まず試すなら、同じフォルダの samples の 3 件をどうぞ。

2. Claude に意味層を書いてもらう

Claude Desktop を一度終了して開き直し、次のように頼みます。

LeXWeft Lite の、まだ意味層が無い資料を読んで、課題と解決手段を根拠の段落つきで書いて。解決手段が課題を解く関係も結んで。

Claude が LeXWeft Lite の道具を使ってよいか尋ねたら、許可してください。

3. 見る・直す

「意味層」タブで、課題と解決手段の一覧、別名、根拠の段落、関係を見て直せます。同じ意味の概念は「まとめる」で 1 つにします。「つながり」タブでは全体を図で見られます。

4. 探す

LeXWeft Lite で「セル間の熱伝播」を解決する手段を、根拠の段落番号つきで一覧にして。言い換えも使って探して。

画面の「検索」タブでも探せます。言い換えは | で区切って並べます（例: 熱暴走 | 延焼 | thermal runaway）。

データについて

何がどこに
資料と意味層ホームフォルダの LeXWeftLite（アプリのフォルダとは別）
LLM に読ませた部分つないだ LLM サービス（Claude Desktop なら Anthropic）に送られます。社外秘の資料は、所属先の決まりを確かめてから使ってください
書き出し「意味層」タブの「意味層を Markdown で保存」

新しい版に替えるとき

  1. 古いフォルダを消し、新しい ZIP を展開したフォルダを同じ場所・同じ名前に置きます。
  2. 入れたときと同じ手順で install.sh（Windows は install.ps1）を実行します。

資料と意味層はアプリのフォルダとは別の場所にあるので、そのまま残ります。置き場所や名前を変えた場合は、Claude への登録をやり直してください（セットアップの最後で y）。

困ったとき

こんなときこうしてください
Claude に LeXWeft Lite の道具が出てこないClaude Desktop を完全に終了して開き直す。それでも出なければ、セットアップを実行し直して最後に y
「アドレスはすでに使用されています」と出るLeXWeft Lite がもう起動しています。ブラウザで http://127.0.0.1:8765/ を開いてください
PDF の本文が出ないスキャン画像の PDF は文字を取り出せません。文字を選択できる PDF を使ってください
セットアップが途中で止まるインターネットにつながっているか確かめて、もう一度実行してください。社内ネットワークで外部の取得が止められている場合があります

そのほか気づいたことは、画面右上の「感想を送る」から教えてください。
