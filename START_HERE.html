LeXWeft Lite のはじめかた

資料を入れると、課題と解決手段のつながりを Claude などの LLM と一緒に作り、図で見て、根拠の段落つきで探せるようになるアプリです。データはこの PC の中に保存します。

Mac の方Windows の方使い方困ったとき
必要なもの
  • macOS 12 以降、または Windows 10 / 11（Windows は試験中）
  • インターネット接続（セットアップのときだけ。必要なものを取ってきます）
  • LLM とつなぐ場合は Claude Desktop（無料プランでも使えます）

はじめる前に、同じフォルダの TERMS.txt（テスト版の利用条件）をお読みください。

Mac での入れ方（5 分ほど）

  1. フォルダを置き場所に移す。 展開したフォルダを「書類」などに移します。
    セットアップのあとでフォルダを動かすと、起動と Claude との接続をやり直すことになります。
  2. ターミナルを開く。 ⌘ + スペースで Spotlight を開き、「ターミナル」と入力して Enter。
  3. セットアップを始める。 ターミナルに bash と半角スペースを 1 つ打ち、フォルダの中の install.sh をターミナルの画面にドラッグして、Enter。 
    bash /Users/あなたの名前/Documents/LeXWeftLite/install.sh
    のように表示されれば正しい形です。
  4. 数分待つ。 必要なものを取ってきて入れます。最後に「Claude Desktop に LeXWeft Lite を登録しますか」と聞かれたら y と打って Enter。
  5. 起動する。 Launchpad か Spotlight（⌘ + スペース）で「LeXWeft Lite」を開きます。ほかのアプリと同じようにウインドウで開き、Dock にも出ます。
    セットアップの最後に「Mac アプリは作れませんでした」と出た場合は、フォルダにできた「LeXWeft Lite.command」をダブルクリックすると、ブラウザで開きます（使っている間はターミナルの窓を閉じないでください）。Mac アプリにしたいときは、ターミナルで xcode-select --install を実行して Apple の開発ツールを入れてから、セットアップをもう一度実行してください。

Windows での入れ方（5 分ほど・試験中）

Windows 版は試験中です。Windows 10 / 11 で動くように作っていますが、実機での確認がまだ十分ではありません。うまく動かないときは、感想フォームで教えてください。

  1. フォルダを置き場所に移す。 ZIP を右クリック →「すべて展開」し、できたフォルダを「ドキュメント」などに移します。
  2. PowerShell を開く。 そのフォルダをエクスプローラーで開き、上のアドレス欄に powershell と入力して Enter。
  3. セットアップを始める。 次を貼り付けて Enter。 
    powershell -ExecutionPolicy Bypass -File .\install.ps1
  4. 数分待つ。 最後に「Claude Desktop に LeXWeft Lite を登録しますか」と聞かれたら y と打って Enter。
  5. 起動する。 フォルダにできた「LeXWeft Lite.bat」をダブルクリック。ブラウザが開いて画面が出ます。

使い方

1. 資料を入れるフォルダを決めて、資料を入れる

「取り込み」タブで、まずこれから資料を入れていくフォルダを決めます（おすすめの場所のまま「このフォルダにする」を押せば作ります）。あとは画面にファイルを落とすか、Finder（Windows はエクスプローラー）でそのフォルダに入れるだけで、自動で取り込んで意味層を作ります。md / txt / html / pdf / docx / csv を読みます。

フォルダの中をサブフォルダに分けると、サブフォルダごとの「グループ」になり、グループどうしの関わりが見られます。すでに資料が入っているフォルダは、画面の下の「すでにあるフォルダから意味層を作る」で登録できます（まず試すなら、同じフォルダの samples をどうぞ）。隠しフォルダ、アプリや開発用のフォルダ、ライセンス文は読みません。

2. 意味層が自動でできる

取り込みが終わると、フォルダごとに資料をベクトルにして、似た資料のまとまり（クラスター）に分けます。各まとまりには、そのまとまりに特に多く出る語が名前として付くので、どんな集まりかが分かります。

3. 見る

  • 地図: 点が資料、近い点ほど中身が似ています。まとまりを押すと、特に多く出る語・代表的な段落・中心に近い資料が出ます。
  • つながり: よく出る語と、一緒に出る語のつながり。色はその語がいちばん多く出るまとまりです。テーマの言葉で絞り込めます。
  • 資料: 資料を開くと、段落番号つきの本文と「似た資料」が出ます。

複数のフォルダをまたいで見たいときは、地図やつながりの範囲で「すべての資料」を選びます。

4. Claude とつながったか確かめる

セットアップの最後に y を押した場合は、次の 2 つを行います。

  1. Claude Desktop をいったん終了して、開き直す。 Mac は Claude Desktop の画面で ⌘Q。Windows は画面右下のタスクトレイの Claude アイコンを右クリックして「終了」。ウインドウの × で閉じるだけでは終了しません。
  2. 新しいチャットで、次のように聞く。
    LeXWeft Lite に入っている資料は何件？
    件数が返ってくれば、つながっています。途中で「LeXWeft Lite を使ってよいか」と聞かれたら、「許可」を押してください。

5. Claude で深める（課題と解決手段）

チャットで、次のように頼みます。

LeXWeft Lite の、まだ意味層が無い資料を読んで、課題と解決手段を根拠の段落つきで書いて。解決手段が課題を解く関係も結んで。

資料が多いときは、テーマを決めて頼みます。

LeXWeft Lite で「熱暴走」に関わる資料から、課題と解決手段を根拠の段落つきで書いて。

Claude が「LeXWeft Lite を使ってよいか」と聞いてきたら、「許可」を押してください。

6. 直す

「意味層」タブで、課題と解決手段の一覧、別名、根拠の段落、関係を見て直せます。同じ意味の概念は「まとめる」で 1 つにします。「つながり」タブでは全体を図で見られます。

7. 探す

「検索」タブの「意味層でたどる」に質問を文で書くと、言い方が違っても関係する資料と段落が出て、「あわせて確かめたい資料」（関係が強いのに見ていない資料）も示します。Claude にも、意味層をたどって調べてもらえます。

LeXWeft Lite で「セル間の熱伝播」を解決する方法を調べて。関係する資料を読み残しがないように確かめてから、根拠の段落番号をつけて答えて。

画面の「検索」タブでも探せます。言い換えは | で区切って並べます（例: 熱暴走 | 延焼 | thermal runaway）。

データについて

何がどこに
資料と意味層登録したフォルダの中の _LeXWeft フォルダ。フォルダごと移動・コピーすると、意味層も一緒に付いていきます。クラウド同期（Dropbox・OneDrive・Google ドライブ・iCloud）のフォルダだけは、ホームフォルダの LeXWeftLite に保存します
フォルダの中身が変わったときアプリを開いている間は、5 分ごとに見て自動で取り込み直します（「取り込み」タブでフォルダごとに止められます）
LLM に読ませた部分つないだ LLM サービス（Claude Desktop なら Anthropic）に送られます。社外秘の資料は、所属先の決まりを確かめてから使ってください
書き出し「意味層」タブの「意味層を Markdown で保存」

新しい版に替えるとき

  1. 古いフォルダを消し、新しい ZIP を展開したフォルダを同じ場所・同じ名前に置きます。
  2. 入れたときと同じ手順で install.sh（Windows は install.ps1）を実行します。

資料と意味層はアプリのフォルダとは別の場所にあるので、そのまま残ります。置き場所や名前を変えた場合は、Claude への登録をやり直してください（セットアップの最後で y）。

困ったとき

こんなときこうしてください
Claude に「LeXWeft Lite に入っている資料は何件？」と聞いても、分からないと言われるClaude Desktop を完全に終了して開き直す（Mac は ⌘Q、Windows はタスクトレイから終了）。それでもだめなら、セットアップを実行し直して最後に y
ブラウザが開かないターミナル（Windows は黒い窓）に出ている http://127.0.0.1:…/ をブラウザで開いてください。8765 番を別のアプリが使っていると、自動で別の番号で開きます
PDF の本文が出ないスキャン画像の PDF は文字を取り出せません。文字を選択できる PDF を使ってください
セットアップが途中で止まるインターネットにつながっているか確かめて、もう一度実行してください。社内ネットワークで外部の取得が止められている場合があります

そのほか気づいたことは、画面右上の「感想を送る」から教えてください。
